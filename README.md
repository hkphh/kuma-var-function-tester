# KUMA Function Tester

Расширение для Chrome, которое позволяет тестировать выражения функций переменных Kaspersky KUMA в реальном времени — без запуска самой KUMA или сработки кореляционного правила.

Вводите выражения, задавайте значения переменных и сразу видите результат вычисления, включая вложенные функции.

---

## Возможности

- Ввод произвольных выражений с функциями KUMA
- Поддержка вложенных функций: `to_lower(to_lower(to_lower(SourceUserName)))`
- Задание значений переменных через удобный интерфейс
- Добавление и удаление переменных одной кнопкой
- Мгновенный вывод результата и понятные сообщения об ошибках
- Поддержка арифметических операций: `+ - * / %`
- Строковые литералы в одинарных или двойных кавычках

## Установка

Расширение не опубликовано в Chrome Web Store, устанавливается вручную в режиме разработчика.

### Шаги

1. **Скачайте или склонируйте репозиторий**

   ```bash
   git clone https://github.com/hkphh/kuma-var-function-tester.git
   ```

   Или скачайте ZIP-архив и распакуйте его.

2. **Откройте страницу управления расширениями в Chrome**

   Перейдите по адресу:

   ```
   chrome://extensions/
   ```

3. **Включите режим разработчика**

   Переключатель **«Режим разработчика»** в правом верхнем углу.

4. **Загрузите расширение**

   Нажмите **«Загрузить распакованное расширение»** и выберите папку `kuma-function-tester`.

5. **Откройте попап**

   Иконка расширения появится на панели Chrome. Нажмите на неё — откроется тестер.

## Использование

Интерфейс состоит из трёх частей:

1. **Поле «Выражение»** — сюда вводится выражение с функциями KUMA.
2. **Список переменных** — пары «имя = значение». По умолчанию одна переменная.
3. **Кнопка «Вычислить»** — запускает парсинг и вычисление выражения.

### Примеры

#### Простая функция

**Выражение:**
```
len(DeviceCustomString1)
```

**Переменная:** `DeviceCustomString1 = Hello World`

**Результат:** `11`

---

#### Вложенные функции

**Выражение:**
```
to_lower(to_lower(to_lower(SourceUserName)))
```

**Переменная:** `SourceUserName = User@Example.COM`

**Результат:** `user@example.com`

---

#### Комбинированное выражение

**Выражение:**
```
append(to_upper(SourceUserName), '!')
```

**Переменная:** `SourceUserName = admin`

**Результат:** `ADMIN!`

---

#### Арифметика

**Выражение:**
```
(len(DeviceCustomString1) + 5) * 2
```

**Переменная:** `DeviceCustomString1 = Hello`

**Результат:** `20`

## Поддерживаемые функции

### Строковые

| Функция | Описание |
|---|---|
| `len(str)` | Длина строки |
| `to_lower(str)` | Приведение к нижнему регистру |
| `to_upper(str)` | Приведение к верхнему регистру |
| `append(a, b)` | Конкатенация `a + b` |
| `prepend(a, b)` | Конкатенация `b + a` |
| `substring(str, start, [end])` | Подстрока |
| `index_of(substr, str)` | Позиция первого вхождения |
| `last_index_of(substr, str)` | Позиция последнего вхождения |
| `tr(str, [chars])` | Обрезка символов с обоих концов |
| `replace(str, from, to)` | Замена всех вхождений |
| `regexp_replace(str, regex, repl)` | Замена по регулярному выражению |
| `regexp_capture(str, regex)` | Извлечение совпадения |
| `str_join(sep, ...items)` | Объединение значений через разделитель |
| `template(str, ...args)` | Шаблонная подстановка |

### Массивы

| Функция | Описание |
|---|---|
| `distinct_items(arr)` | Уникальные элементы |
| `sort_items(arr, [dir])` | Сортировка (`asc` / `desc`) |
| `item(arr, index)` | Элемент по индексу |
| `math_min(arr)` | Минимум |
| `math_max(arr)` | Максимум |
| `math_avg(arr)` | Среднее |

### Математические

| Функция | Описание |
|---|---|
| `round(x)` | Округление |
| `ceil(x)` | Округление вверх |
| `floor(x)` | Округление вниз |
| `abs(x)` | Модуль |
| `pow(x, y)` | Возведение в степень |

### Условные

| Функция | Описание |
|---|---|
| `conditional(cond, trueVal, falseVal)` | Тернарная логика с поддержкой `=`, `!=`, `LIKE`, `ILIKE`, `AND`, `OR` |

| Функция | Описание |
|---|---|

## Ограничения

- **Функции доступа к данным KUMA не поддерживаются** — `active_list`, `table_dict`, `dict`, `context_table`. Они требуют подключения к реальным источникам данных KUMA.
- **Не реализованы побочные эффекты и внешние зависимости** — расширение работает полностью автономно в браузере.
- Реализация `conditional` упрощена: поддерживаются операторы `=`, `!=`, `LIKE`, `ILIKE` и логические связки `AND` / `OR`.

### Как это работает

1. **Токенизация** — входное выражение разбивается на токены (имена, числа, строки, операторы, скобки).
2. **Парсинг** — строится AST (абстрактное синтаксическое дерево) с учётом приоритетов операций и вложенных вызовов функций.
3. **Вычисление** — рекурсивный обход AST с подстановкой значений переменных и вызовом соответствующей реализации функции.
4. **Вывод** — результат рендерится в блоке результата; ошибки парсинга и вычисления показываются красным.
